# V12.1.2 — Ferramentas ligadas às formações

Não requer SQL novo.

## Regras finais de acesso
- Documentação Imobiliária Profissional → Checklist documental
- Terrenos e Potencial Construtivo → Analisar Terreno
- Urbanismo Prático → Alterar Uso
- Prática Profissional Avançada → Analisar Imóvel

O menu só mostra a ferramenta quando o formando tem acesso à formação correspondente.

Também existe proteção de rota:
- escrever o URL diretamente não contorna o acesso;
- a gravação de Analisar Imóvel também confirma o acesso no servidor.

O Pack Profissional Completo, quando for criado comercialmente, só precisa atribuir acesso às quatro formações; as quatro ferramentas ficam automaticamente disponíveis.
