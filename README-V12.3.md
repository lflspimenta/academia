# V12.3 — Glossário Profissional aprofundado

Revisão editorial de **102 entradas** do Glossário Profissional.

## O que mudou
- Definições deixam de ser telegráficas e passam a explicar contexto e aplicação profissional.
- Aprofundamento especial de intervenientes: Promotor Imobiliário, Developer, Proprietário, Vendedor, Construtor, Empreiteiro, Mediadora e Consultor Imobiliário.
- Aprofundamento de CMI, CPCV, Due Diligence, PDM, PIP, Lead, Angariação, Exclusividade e Comissão.
- Restantes entradas receberam contexto formativo específico da respetiva categoria.
- Corrigido o import `BookOpen` em `components/AppShell.tsx`.

## Instalação
1. Atualize o projeto com esta versão.
2. Se o glossário V12.2 já foi criado na base de dados, execute apenas `supabase/v12_3_glossario_definicoes_aprofundadas.sql`.
3. Faça novo deploy.

Não altera as cinco formações, progresso, testes, certificados ou acessos.
