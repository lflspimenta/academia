# V14 — Sem pressupostos

Esta versão corrige o princípio pedagógico da Academia:

**definir → explicar → exemplificar → praticar**

Mudanças:
- 191 aulas atualizadas.
- Módulo 1 / Aula 1 explica mediação imobiliária desde zero: cliente, empresa de mediação, consultor, destinatário, licença, IMPIC e introdução explícita ao nome completo CMI.
- Siglas e conceitos são apresentados pelo nome completo antes de serem usados.
- Interações deixaram de ser disparadas por palavras genéricas. Passam a existir apenas em aulas onde o conceito já foi ensinado.
- O caso de CMI foi removido da primeira aula de Iniciação.
- Caderneta, Certidão, CMI, CPCV, PDM, PIP, RAN/REN, FINE, fiscalidade, AML e RGPD receberam blocos explicativos próprios.
- IDs, slugs, módulos e testes mantidos.

Aplicação:
1. Opcional: editar e executar `00_reset_testers.sql`.
2. Executar os 5 SQL dos cursos.
3. Fazer deploy desta versão.
