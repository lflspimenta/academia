# V6.2 — Posso mudar o uso deste imóvel?

1. Execute `supabase/v6_2_use_change_analyzer.sql` no Supabase.
2. Publique esta versão da app no GitHub/Vercel.
3. Abra `/alteracao-uso`.

A ferramenta:
- pergunta uso atual e pretendido;
- distingue fração autónoma;
- pergunta se o uso atual está confirmado;
- distingue alteração com/sem obras;
- gera checklist, alertas e próximos passos;
- classifica o resultado como Potencialmente viável, Necessita verificação ou Existem obstáculos a analisar;
- permite guardar a análise por utilizador.
