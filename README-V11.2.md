# V11.2 — Certificado PDF + QR

Não requer SQL novo.

## O que acrescenta
- Botão “Descarregar certificado PDF”.
- Impressão otimizada em A4 horizontal.
- QR Code para a página pública de validação.
- Identidade Academia Imobiliária no documento.
- Mantém código único, resultado, carga horária e data.

## Nota sobre PDF
O botão abre a caixa de impressão do navegador já formatada para o certificado.
Escolha “Guardar como PDF”. Isto evita guardar ficheiros PDF duplicados no servidor e mantém o documento sempre ligado ao certificado verificável.

## Publicação
Substitua os ficheiros no GitHub e faça novo deploy na Vercel.
