# V12 — Admin Profissional

## Áreas
- Visão Geral
- Utilizadores
- Ficha individual do formando
- Acessos às formações
- Conteúdos: cursos, módulos, aulas, publicação e revisão jurídica
- Editor de conteúdo de aulas
- Avaliações: testes, percentagem mínima, novas perguntas, métricas
- Certificados: consulta, validação, invalidação e reativação
