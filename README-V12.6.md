# V12.6 — Sistema Interativo Completo

Atualização de código. Não requer SQL.

Inclui, de forma contextual dentro das aulas existentes:
1. “O que faria?” / decisões profissionais com feedback imediato.
2. Mini-checks sem nota.
3. Casos práticos por etapas.
4. “Encontre o erro”.
5. Classificação de risco Verde / Atenção / Crítico.
6. Simulador rápido de triagem de terrenos.
7. Ordenação de processos.
8. Verdadeiro ou mito.
9. Checklist interativa de aprendizagem.
10. Casos profissionais finais de treino antes da avaliação formal, em aulas de revisão/casos.

Mantém o Laboratório de Caderneta Predial da V12.5.

Importante:
- As interações não contam para a nota.
- Não alteram os testes formais, certificados ou progresso existente.
- Não requerem alterações à base de dados.
- Foram desenhadas para desktop e mobile.
